FAQ & troubleshooting

Short answers first. If yours isn't here, About → Report a problem in the app copies diagnostic info (never what you dictated) and opens a bug report.

Questions

Is it really free?

Yes. No account, no subscription, no word limit, no ads. The source code is open under the MIT licence. Only the optional cloud options use a provider's API, with your own key (Groq has a free tier).

Does it need the internet?

Only to download it and a speech model once. After that, local Whisper works offline. Update checks need the internet, but the app works without them.

Why does Windows warn me when I install it?

The installer isn't code-signed yet, so SmartScreen says “Windows protected your PC”. Click More info, then Run anyway. It doesn't mean a virus was found. See what to do and the code signing policy.

My antivirus flags it. Is it safe?

New, unsigned apps are often flagged by heuristics, more so one with a keyboard hook (that is how it sees your shortcut). Every release is built by GitHub Actions from the public source code. If you are unsure, check the file on VirusTotal to see which engines flag it, and tell us in an issue.

Does my voice go anywhere?

No, unless you turn on a cloud option (cloud speech recognition, Command mode, or AI polish with a cloud service). The app says next to each one what leaves the PC. See Privacy.

Which speech model should I pick?

The setup suggests one for your PC. Roughly: Base for English on an ordinary laptop, Small for other languages, Large v3 Turbo on a PC with a good graphics card. Change it in Settings → Speech recognition.

Is there a Mac or Linux version?

No. Pauli Speaks is made for Windows 10 and 11. The comparison lists apps for other systems.

Can I use it on a work PC where I can't install software?

Try the portable copy: it runs without installing and keeps its data next to the .exe. Ask your IT department first if you aren't sure it's allowed.

Troubleshooting

Nothing happens when I hold Ctrl + Win

Another dictation app (Wispr Flow, for example) might use the same shortcut. Quit it, or change the shortcut on the Shortcuts page. Home says so when it sees one running.

“Pauli Speaks can't see your shortcut”

The keyboard hook that watches for your shortcut didn't start. Security or antivirus software sometimes blocks it: allow Pauli Speaks there, then restart it (tray icon → Quit Pauli Speaks, then start it again). If the banner stays, restart the PC. Separately, while an app running as administrator is in front, Windows hides your keys from Pauli Speaks unless it also runs as administrator. About → Logs opens the log, which says why the hook failed.

Text doesn't appear in one app

Windows blocks simulated typing into apps running as administrator. Then Pauli Speaks leaves the text on the clipboard and the pill says Copied. Press Ctrl+V. If that didn't happen, use Paste last transcript (Shift + Alt + Z) or copy it from History.

“No sound. Is your mic muted?”

The microphone delivered only silence. Check that it isn't muted (a switch or key on the microphone, or in Windows sound settings), that Settings → Microphone is the one you use, and that Windows lets desktop apps use it (see “Microphone blocked”). Settings → Run setup again tests the microphone.

“No speech detected”, although I spoke

Silence detection thought it heard no speech, for example in a very quiet recording or with a distant microphone. Speak closer to the microphone, or turn off Settings → Dictation → Silence detection.

“Couldn't transcribe. Retry”

The speech engine failed or the cloud service couldn't be reached. Click Retry on the pill or on the entry in History. The recording is kept in memory until you quit (the last 5 recordings or 10 minutes of audio).

“Microphone blocked”

Turn on Windows Settings → Privacy & security → Microphone → Let desktop apps access your microphone.

It's slow

Use Whisper Base or Tiny, pick a single language, or switch to a cloud service with a free Groq key (your audio then goes to Groq).

Something in the setup was skipped or went wrong

Settings → Run setup again goes through languages, microphone, speech engine and shortcut once more.

I have version 1.3.0 to 1.5.0 and it doesn't update

Those versions stopped part-way through starting, so they can't update themselves. End Pauli Speaks in Task Manager, then install the latest version from this site.
