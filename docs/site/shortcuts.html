Shortcuts, Stream Deck and pedals

Dictate with the keys you like, a foot pedal, a mouse button or a Stream Deck button.

The default shortcuts

PressWhat it does
Ctrl + Win, holdDictate: talk while you hold, let go to paste
Ctrl + Win twice, or Ctrl + Win + SpaceHands-free: keeps listening until you press it again
EscCancel the dictation
Ctrl + Win + Shift, holdSpeak your language, paste English (the Translate to English mode)
Ctrl + Win + Alt, holdCommand mode: select text and say “make this more formal”, or say what to write (needs a free Groq key)
Shift + Alt + ZPaste the last transcript again
Shift + Alt + SRead the selected text aloud

Your own shortcuts

On the Shortcuts page, each action takes up to four shortcuts (Dictate up to eight, one per mode). Each one is Hold, Toggle or Both (hold, or double-tap to lock). A shortcut can be:

  • 1–3 keys, or a single F-key (F13–F24 are free for pedals and Stream Deck),
  • a right-side modifier such as the right Ctrl,
  • a mouse button (the side buttons, for example),
  • a double-tap of Ctrl, Alt or Shift.

Combinations Windows keeps for itself are refused, and app shortcuts like Ctrl+C ask first. The Test a key, pedal or mouse button box shows exactly what Pauli Speaks sees. Extra actions: Copy last transcript, Undo last dictation, Press Enter and Switch mode.

Foot pedals and macro keypads

Most pedals and keypads come with software that can send a key. Let yours send a key no app uses, such as F20, then add F20 on the Shortcuts page with Hold: press the pedal to talk, let go to paste. That is real push-to-talk, with no extra program.

Links and command line

Other programs can control Pauli Speaks with a link or a command-line flag. The Shortcuts page in the app lists them, with the exact path of your copy and a Copy button.

Links (installed app only)

LinkWhat it does
pauli-speaks://dictate/toggleStart or stop
pauli-speaks://dictate/startStart hands-free
pauli-speaks://dictate/stopFinish and paste
pauli-speaks://dictate/cancelCancel
pauli-speaks://dictate/toggle?mode=codeAny link can name a mode

Any web page can open a link, so links only control dictation. They can't paste or press keys.

Command-line flags

The installed app is "%LOCALAPPDATA%\Programs\Pauli Speaks\Pauli Speaks.exe", unless you chose another folder when installing.

FlagWhat it does
--toggleStart or stop
--startStart hands-free
--stopFinish and paste
--cancelCancel
--paste-lastPaste the last transcript again
--copy-lastCopy the last transcript
--undo-lastUndo the last dictation
--press-enterPress Enter
--mode=<id>With --toggle or --start: dictate in that mode

A mode's id is shown on the Modes page. The built-in ones are default, chat, code, formal and translate. Each call starts Pauli Speaks.exe for a moment, which hands the command to the copy that is already running.

Stream Deck

The Pauli Speaks plugin

The plugin adds five buttons: Toggle dictation, Start, Stop, Cancel and Paste last. Toggle and Start can name a mode in the key's settings. The buttons only send commands to the app; the plugin makes no network calls. It needs Windows 10 or 11, Stream Deck 7.1 or newer, and the installed app (the portable copy has no links).

Get com.pauli.speaks.streamdeck.streamDeckPlugin, double-click it and drag the buttons from the Pauli Speaks group onto your keys. How to get or build the file, and what each button sends: the plugin on GitHub.

Without the plugin

A Stream Deck button sends one press, so use toggle: press to start, press again to paste.

  • Dictate: add the Website action (under System) with the URL pauli-speaks://dictate/toggle, or pauli-speaks://dictate/toggle?mode=chat for a mode. Leave its background (GET request) option off, so that Windows opens the link.
  • Paste last, Undo last, Press Enter: make a Windows shortcut (right-click the desktop → New → Shortcut) with the target "%LOCALAPPDATA%\Programs\Pauli Speaks\Pauli Speaks.exe" --paste-last, then point the Open action (under System) at that shortcut.
  • Or a key: the Hotkey action can send F13; add F13 on the Shortcuts page with Toggle.

AutoHotkey

For AutoHotkey v2. Save it as a .ahk file and run it.

#Requires AutoHotkey v2.0
PauliSpeaks := EnvGet("LOCALAPPDATA") "\Programs\Pauli Speaks\Pauli Speaks.exe"

; Ctrl+Alt+D: start or finish a dictation in the Chat mode
^!d::Run('"' PauliSpeaks '" --toggle --mode=chat')

; Hold F20 to talk, let go to paste (KeyWait ignores the key repeating)
F20:: {
    Run('"' PauliSpeaks '" --start')
    KeyWait("F20")
    Run('"' PauliSpeaks '" --stop')
}

; Ctrl+Alt+Z: take the last dictation back
^!z::Run('"' PauliSpeaks '" --undo-last')

; Ctrl+Alt+E: press Enter, for example to send a chat message
^!e::Run('"' PauliSpeaks '" --press-enter')

; A link works too
^!t::Run("pauli-speaks://dictate/toggle")

If all you need is push-to-talk on one key, set that key on the Shortcuts page instead: it reacts faster than a script, because nothing has to start.

AI agents

A skill for AI coding agents, such as Claude Code, lets the agent start and stop dictation through the links when you ask it to (“let me talk”, “stop listening”), so you can say your next message instead of typing it. It installs nothing and sends nothing anywhere. See the skill on GitHub; all integrations are in integrations.
