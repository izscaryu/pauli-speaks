Pravila potpisivanja koda

Stanje: izdanja aplikacije Pauli Speaks još nisu digitalno potpisana, pa Windows pri pokretanju instalacijskog programa prikazuje upozorenje SmartScreen (što učiniti). Ova stranica navest će uslugu za potpisivanje i certifikat kad izdanja budu potpisana.

Kako se izdanja grade

  1. Održavatelj označi commit na grani main u javnom repozitoriju (v1.2.3).
  2. GitHub Actions iz tog commita, na GitHubovim poslužiteljima, gradi instalacijski program Pauli-Speaks-Setup-<verzija>.exe i pokreće testove. Ništa izgrađeno na osobnom računalu ne objavljuje se.
  3. Instalacijski program, njegov .blockmap i latest.yml objavljuju se kao izdanje na GitHubu. Ažuriranje u aplikaciji provjerava latest.yml prije instalacije.

Pauli Speaks preuzimaj samo s GitHub Releases (gumb za preuzimanje na ovoj stranici vodi onamo). Naziv proizvoda u instalacijskom programu je „Pauli Speaks”, a verzija je verzija izdanja. Tijek rada za izdanja je javan.

Što će biti potpisano

Kad potpisivanje bude uvedeno, potpisivat će se samo instalacijski program koji iz ovog repozitorija izgradi tijek rada za izdanja, nakon što održavatelj odobri svako izdanje, a latest.yml će se ponovno izraditi za potpisanu datoteku. Ništa iz drugih projekata neće biti potpisano.

Privatnost

Pauli Speaks pretvara govor u tekst na tvom računalu. Spaja se na GitHub radi provjere ažuriranja i na Hugging Face radi preuzimanja modela za govor i prijevod, a zvuk ili tekst šalje pružatelju u oblaku samo ako uključiš opciju u oblaku. Vidi Privatnost.
