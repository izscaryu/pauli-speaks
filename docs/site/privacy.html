Privacy

Pauli Speaks turns your speech into text on your own PC. There is no account, no analytics and no telemetry. Nothing you say leaves your computer unless you turn on a cloud option, and the app says so next to that option.

This is a summary. The full statement, with every file and connection, is PRIVACY.md; its history on GitHub shows every change.

What stays on your PC

  • Audio. The microphone records only while you dictate, and silence detection runs on your PC. So that a crash doesn't lose what you said, the recording in progress is written to the recovery folder (not encrypted) and deleted when the dictation ends. After a crash, Home asks whether to recover it or discard it. You can turn this off: Settings → Privacy → Recover dictation after a crash.
  • Recordings, off by default. With Keep recordings for 24 hours on, each dictation is kept as a WAV file (not encrypted), so you can play it or transcribe it again from History. They are deleted after 24 hours.
  • Retry and Undo. A dictation that couldn't be transcribed is kept in memory (the last 5, or 10 minutes of audio), so you can retry it until you quit. A cancelled one is kept for 4 seconds, so you can undo the cancel.
  • Transcripts. History keeps your last 500 dictations. Transcript history changes that to Delete after 24 hours or Don't keep.
  • Clipboard history. To paste, the text is put on the clipboard for a moment, marked so that Windows clipboard history (Win+V) and cloud clipboard don't keep it. Your own clipboard content is put back afterwards.
  • AI polish on this PC, off by default. With Ollama, LM Studio, Foundry Local or another server at localhost, the text of each dictation in a mode with a polish level goes to that program on your PC. Nothing leaves the PC for it.
  • Your dictionary, snippets, voice commands and settings.
  • Logs with timings, the detected language, the name of the app you dictated into and errors. Never what you said.

What leaves your PC, only if you choose it

You turn onWhat is sentTo
Cloud API speech recognitionThe audio of each dictation and of files you transcribe, and your dictionary words as a hintThe provider you set up (Groq by default: api.groq.com)
Command modeThe selected text and your spoken instruction, as textThe same provider
AI polish with the Cloud API, or another server that isn't this PCThe text of each dictation in that mode (not the audio) and the mode's polish instructionsThat provider or server
Foundry Local: Show models and DownloadWhich models are offered, and the model you download. Never your textMicrosoft's Foundry Local catalogue and download servers

These need an API key that you get from the provider yourself. The key is encrypted with Windows (DPAPI). What a provider does with your data is up to its own privacy policy.

Connections the app makes by itself

  • Update checks to GitHub, 15 seconds after start and every 6 hours. Only the release information and, when there is an update, the installer are downloaded.
  • Model downloads from Hugging Face, the first time you use a speech or translation model.
  • Foundry Local, only while it is chosen for AI polish. Pauli Speaks starts it with its optional telemetry off. Microsoft documents that it may still send a minimal event about the process when it starts; it contains nothing you dictated. Choose another AI polish option to avoid it.

Nothing else. Read aloud uses the voices built into Windows, and the links and command-line flags only control the app on your PC.

Where your data is, and how to delete it

Everything is in %APPDATA%\Pauli Speaks (About → Data folder opens it). The portable copy keeps it in Pauli Speaks Data next to its .exe.

  • Delete all my data (Settings → Privacy) deletes your history, recordings, dictionary, snippets and settings, including the API key. Models are kept.
  • Delete downloaded models removes the speech, translation and AI polish models; they download again when needed.
  • To remove everything, logs included: quit Pauli Speaks, uninstall it, and say yes when the uninstaller asks whether to delete your data (or delete the folder yourself).

This website

This site has no cookies, no analytics and no trackers, and loads nothing from other sites. The Download button asks GitHub's API (api.github.com) once for the latest version; like any web request, that shows GitHub your IP address. The site is hosted on GitHub Pages; see GitHub's privacy statement.
