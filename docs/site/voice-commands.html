Voice commands

Say a command while you dictate, in any language, and Pauli Speaks does it instead of typing it.

Ready to use

SayWhat happensWhere
“new line” · “novi red”A line breakAnywhere
“new paragraph” · “novi odlomak”An empty lineAnywhere
“press enter”, “send it” · “pošalji”Presses Enter, for example to send a chat messageAt the start or end
“scratch that” · “obriši to”Removes the last dictationAt the start or end

Enter and “scratch that” only count at the start or end of what you say, so “I'll send it tomorrow” stays text. Commands work in any case and without diacritics (“posalji”), and “new line”, “newline” and “new-line” are the same.

Your own commands

Edit them under Voice commands on the Shortcuts page. Each command takes up to 12 phrases, in any language, and does one of these:

  • type text in place of the phrase (anywhere in a sentence),
  • type a snippet (anywhere in a sentence),
  • press a key: Enter, Tab, Escape or Backspace (at the start or end),
  • undo the last dictation (at the start or end).

A mode can switch voice commands off, for example for dictating code.

Snippets and the dictionary

On the Dictionary & snippets page: say “my email” and your address is typed. The dictionary holds names and words Whisper should spell your way; they are also given to Whisper as a hint, so it hears them right the first time.

Command mode is something else

Hold Ctrl + Win + Alt, select text and say “make this more formal” or “translate to German”, or say what to write with nothing selected. That uses an AI model through a free Groq key, so the selected text and your instruction go to Groq.
