Getting started

From download to your first dictation in about five minutes.

You need Windows 10 or 11 (64-bit), a microphone, and the internet once to download a speech model (Whisper Base is about 150 MB). After that it works offline.

  1. Download

    Download for Windows

    The latest version from GitHub · Windows 10 and 11, 64-bit

  2. Install

    Run Pauli-Speaks-Setup-<version>.exe. It installs for your Windows user, without administrator rights, and puts a shortcut on the desktop.

    “Windows protected your PC”?

    When you run the installer, Windows may show a blue screen that says Windows protected your PC and Publisher: Unknown publisher. To install anyway:

    1. Click More info.
    2. Check that the file is Pauli-Speaks-Setup-<version>.exe.
    3. Click Run anyway.

    This happens because the installer isn't code-signed yet. Microsoft Defender SmartScreen warns about any download that has no publisher signature or that few people have run. It doesn't mean a virus was found. Every installer is built from the public source code by GitHub Actions, so download it only from this site or from GitHub Releases. The code signing policy shows where signing stands.

  3. The guided setup

    The first time it starts, a short setup asks which languages you speak, checks your microphone, suggests a speech engine for your PC (it shows what it will download, and downloads nothing until you confirm), checks your shortcut, and lets you try a first dictation. Settings → Run setup again opens it again later.

  4. Dictate

    Click where you want the text, hold Ctrl + Win, speak, and let go. Your words are pasted where the cursor is. A small pill at the bottom of the screen shows that it's listening.

    • Hands-free: double-tap Ctrl + Win (or press Ctrl + Win + Space) to keep listening, then press it again to finish. Up to 20 minutes per dictation.
    • Cancel: Esc. The pill shows Cancelled. Undo for 4 seconds, in case you pressed it by mistake.
    • Paste it again: Shift + Alt + Z pastes the last transcript.

  5. Make it yours

    • Shortcuts: your own keys, a pedal or a mouse button. See Shortcuts & pedals.
    • Modes: language, translation, style and voice commands per shortcut or per app.
    • Dictionary & snippets: names and words it should spell your way, and phrases like “my email” that type your address.
    • Settings → AI polish: tidy what you said with a model on your PC (Ollama, LM Studio or Foundry Local) or in the cloud. Off until you choose it.

Speech engines

Local Whisper comes in four sizes: Tiny, Base, Small and Large v3 Turbo. Bigger is more accurate and slower. On a PC with a DirectX 12 graphics card it runs on the graphics card, 2–3 times faster, and falls back to the processor by itself. You can also use a cloud service with an OpenAI-compatible API (Groq's free tier is the default) and your own key, which is encrypted by Windows; your audio then goes to that service.

Updates

The installed app checks GitHub for a new version 15 seconds after it starts and then every 6 hours. It downloads the update in the background and offers Restart to update in the tray, the window and About. If you ignore it, the update installs the next time you quit. Turn on About → Get early versions to get test versions before everyone else.

Portable copy

Pauli-Speaks-Portable-<version>.exe, on the same releases page, runs without installing, for example from a USB stick or on a work PC. Put it in a folder of its own and run it. It keeps everything in a Pauli Speaks Data folder next to the .exe.

  • No automatic updates: About shows a link when there is a new version. Replace the .exe and keep the data folder.
  • No pauli-speaks:// links and no Start with Windows, so it leaves nothing in the registry. The command-line flags work, but slowly.
  • It starts a few seconds slower, because it unpacks itself every time.

Uninstall

Quit Pauli Speaks (tray icon → Quit Pauli Speaks), then uninstall it in Windows Settings → Apps. The uninstaller asks whether to delete your data too (history, settings, models); the default is to keep it. It also removes the pauli-speaks:// links and the Start with Windows entry. Updates never touch your data.
